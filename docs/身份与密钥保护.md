# 身份与密钥保护

首次启用账号页时，使用原有 PUBLIC_ACCESS_USERNAME / PUBLIC_ACCESS_PASSWORD 创建管理员，密码不因迁移改变。之后账号与密码由数据库管理，重启不会用环境变量覆盖页面修改。
业务身份在服务端绑定，不接受浏览器声明的角色或密级。管理员内部用户 ID 默认保持 web-demo，以兼容原问答审计记录。

普通账号用户名默认为 tunnel-reader。未配置密码时迁移为停用状态；管理员在“账号管理”设置新密码、选择启用后即可使用。环境变量仅用于首次迁移，不再用重启来修改已有账号。密码不要写入聊天或提交进代码仓库。
普通账号为 field_engineer，默认可查看公开/内部知识、问答、导出自己的报告和查看自己的审计。不能上传/删除资料、维护图谱或修改模型设置。
页面可新增账号、修改名称、角色、状态和密码；新建普通账号为 internal，管理员为 confidential。账号名不能重复。修改需要确认管理员当前密码，不能停用或降级自己。

浏览器使用登录页与可撤销的 HttpOnly / SameSite 会话 Cookie，HTTPS 下设置 Secure；有效期 8 小时。每次账号修改都会撤销该账号的现有会话，退出登录也即时撤销。账号密码使用带随机盐的 PBKDF2-SHA256（600000 次）哈希存储；明文不回显。

表单登录按账号每分钟最多 10 次失败、全局每分钟最多 100 次失败限流；命令行兼容 Basic 认证保留原失败计数限制。浏览器不使用 Basic 缓存身份，以确保退出后不会自动重新登录。多进程部署应迁移到共享限流器。

会话写请求校验 CSRF Token 和来源域名，验证错误不回传输入密码。账号变更记录写入 account_events。已有较短管理员密码保留兼容；新设密码至少 8 位。

原 API Key 环境变量继续使用，不会被复制进数据库。页面保存的密钥用带版本标记的密文保存：

- Windows 默认使用当前服务账户的 DPAPI；更换 Windows 账户或机器前应准备凭据迁移。
- 其他平台先设置 TUNNEL_QA_SECRETS_ENCRYPTION_KEY（Fernet 密钥），应用不会在缺少加密配置时明文保存。
- Windows 也可使用上述环境变量，以支持受控迁移；加密密钥须独立于数据库备份保管。
- 旧明文设置在启动时自动迁移。已有历史备份或数据库空闲页可能仍含旧值，不能把本次逻辑迁移等同于历史介质擦除。
- 页面“清除已保存 Key”会清空当前进程密钥；若操作系统仍配置环境 Key，重启后它仍可能生效。彻底停用时需管理员删除环境配置。

非公网模式默认仅允许回环地址本地管理。仅当实际部署在可信身份网关后方、网关覆盖身份头且后端不能被直连时，才设置 TUNNEL_QA_TRUST_IDENTITY_HEADERS=true。公网模式即使启用此选项也不信任客户端头。

Fernet API 依据：https://cryptography.io/en/latest/fernet/ 。
