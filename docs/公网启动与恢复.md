# 公网启动与恢复

首次在项目目录运行 `powershell -ExecutionPolicy Bypass -File scripts/start_public_demo.ps1 -Domain "<你的-ngrok-域名>"`。
后续可省略域名，使用进程环境变量 `TUNNEL_QA_PUBLIC_DOMAIN` 或本机 `.runtime/public-status.json` 中保存的域名；仓库不包含个人域名。
脚本可重复运行：服务正常时复用，停止时重新启动，不会为了更新配置自动杀死正在工作的服务。

- 启动前检查实际认证配置，而不是只检查 `.env` 是否存在。
- 当前进程缺少 DeepSeek 配置时，从 Windows 用户/机器环境读取，密钥不写入日志或命令行。
- 本地服务健康、匿名访问被拒绝、管理员身份均通过后才启动隧道。
- 区分隧道注册成功和真实公网可用；只有 `PublicReady: true` 才表示本机从公网入口检查通过。
- 状态保存在 `.runtime/public-status.json`，包括检查时间。它是一次检查结果，不是持续监控。
- 遇到占用端口的未知进程、错误上游或错误域名会退出，不自动停止其他程序。
- 新进程日志按时间保存，不覆盖旧日志。恢复网络后可以重新运行启动脚本。

停止时运行 `scripts/stop_public_demo.ps1`。脚本核对 PID、可执行文件、启动命令和进程创建时间；不使用旧的纯 PID 文件，也不停止无法核验的旧 Cloudflare 隧道。

当前验证：复用已启动服务、公网健康 200、未认证 401、管理员身份 200；失败场景通过隔离测试。未做断电重启演练、未安装开机启动或持续守护服务。

电脑需要保持开机、联网且服务运行。固定域名不等于永久在线，也不能保证不同地区网络均可访问。现有短管理员密码保持兼容，仍建议随后更换强密码。
