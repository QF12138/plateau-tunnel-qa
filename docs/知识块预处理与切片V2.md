# 知识块预处理与切片 V2

更新时间：2026年10月20日

## 使用方法

进入「文档入库」，选择文件，在切块参数中选择「关键正文切块」；这是新入库的默认策略。先点击「预览知识块」，检查正文、章节、页码及排除记录，再上传入库。预览仅在内存中处理，不保存文件、切块或图谱数据。

预览最多展示前20块，并显示总块数。修改文件、资料类型或切块参数后，需要重新预览。入库后可以在「资料治理」查看完整知识块和处理报告。

## 处理路线

原文件 → 正文解析 → 清理版面噪声 → 识别章节和非正文部分 → 按完整句子、条款和表格行组合 → 保存原文与知识块 → 沿用知识抽取、审核发布和问答检索流程。

1. **完整保留原文**：原文件与解析文本保存到原文库，检索知识块保存到切块库。排除内容不进入新知识块，但不会从原文件中删除。
2. **清理后再切块**：PDF 优先使用按位置排序的文本提取，修复常见中文断行及空格；明确的双栏正文按左栏到右栏读取，通栏标题或摘要分隔阅读区域。横跨栏间空白但仍属于左栏的标题不会截断阅读顺序；有线表格、单栏及不确定版式回退常规提取。过滤明确的重复页眉页脚、页码和提取噪声。
3. **保守选择正文**：识别目录、参考文献、致谢、出版声明等明确的非正文区域。参考文献与结论同页时保留结论；不能可靠判断的内容保留，不凭关键词猜测删除。
4. **保持证据完整**：尽量保留条款、条件、否定词、数字和单位；独立正负号不会作为装饰线删除，短科学量值及复合单位不会作为独立标题删除。按位置关联紧邻数值的上标，避免上标排到数值前面，但不猜测或改写公式。结构化表格按整行组织并重复表头。明确跨页延续的句子保留页码范围。短定义不会仅因字数少被删除。
5. **参数含义**：块大小是目标字符数，overlap 是完整句重叠的上限，不保证每块一样长。过长单句会拆分并警告；无法拆开的超大表格行会提示复核，超过10,000字符的块不允许入库。
6. **可核对处理过程**：处理报告包含块数、排除原因、最多20条排除样例、低文本页和质量提示。预览与正式入库使用相同处理引擎。
7. **联动与兼容**：新知识块继续进入现有图谱候选抽取和问答流程；关键正文块完整传给问答证据，不再一律截断到1,000字符。重复提交复用原记录及处理报告，不重复创建图谱数据。
8. **统一入库质量门槛**：预览、上传和批量导入共用有效正文、切块非空及单块长度检查。批量导入在原文库、分块库写入成功后提交发布；原始文件与清单摘要不一致时拒绝入库，归档不再使用会随输入文件改动的硬链接。
9. **证据和权限联动**：同一知识的多个来源共同参与图谱检索加权；证据详情和审核列表逐条检查文档与分块密级，关系检索同时检查两端实体权限。删除主要来源后切换证据不会绕过这些检查。
10. **内容库恢复**：缺少原文或部分分块镜像时补缺，不覆盖历史块；写入冲突或失败回滚本次新增记录，不删除已有镜像。旧版元数据无效时读取降级为未知，不把历史分块误标为新的关键正文策略。

## 边界与注意事项

- 这是本地规则清理与结构切块，**不是大模型摘要、语义重要性打分或微调**。不会自动改写原文。
- 「完整正文切块」保留参考文献等章节，只进行通用清理及结构切块。旧 `same_as_answer` 参数兼容映射到该策略，不调用回答模型进行切块。
- 扫描PDF没有文字层时，当前上传流程会提示需要OCR核对，尚未自动完成OCR或图片语义理解。已有离线OCR文本在语料导入时继续保留。
- 图片、复杂公式、多栏排版和复杂PDF表格仍需人工核对。纯文本无法完整还原这些信息；低文本或异常编码提示不能替代逐页质量验收。
- 旧库可通过 `scripts/rechunk_corpus.py` 在离线副本执行版本化重切，保留历史块以供审计溯源，并将当前检索和图谱主证据迁移到新版本。必须先备份，再验证原文、历史问答与人工知识未改变，最后停服切换；不能直接对运行中的库执行覆盖。新克隆不包含已有业务库。
- 同样的文字在不同文件或页码中可能是不同证据，不做跨文档去重。

## 验证入口

- `tests/test_knowledge_chunking.py`：条款、单位、页码、章节排除、表格、PDF/Word解析等。
- `tests/test_pdf_layout.py`：双栏阅读顺序、通栏分段、左栏长标题、上标顺序、字符保留，以及单栏/表格/空白扫描页回退。
- `tests/test_knowledge_ingestion.py`：只读预览、原文与块库一致性、重复提交、权限、完整问答证据、跨页引用和旧元数据兼容。
- `tests/test_content_store_recovery.py`：镜像补缺、冲突/写入失败回滚、旧元数据兼容及幂等重放。
- `tests/test_graph_evidence_visibility.py`：多来源图谱加权、逐条证据权限、删除主来源后的权限以及审核列表保护。
- `tests/test_corpus_importer.py`：批量质量门槛、原文/分块镜像、摘要校验和失败不发布。
- `tests/knowledge_ingestion_ui_check.js`：隔离测试库中的预览、参数切换、实际入库、资料治理全文查看、键盘操作和移动端布局。
- `tests/workspace_layout_check.js`：各功能模块的响应式布局回归。
- `test_data/knowledge_preprocessing/关键知识切片示例.md`：专门编写的合成测试文档，不作为现场施工依据。

后端测试命令：`python -m pytest -ra`。浏览器脚本必须对隔离的 `tests/auth_ui_preview.py` 服务运行，不能向生产库写入测试资料。
