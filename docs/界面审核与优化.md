# 界面审核与优化记录

日期：2026年10月13日。范围：登录、账号管理，以及知识问答、知识图谱、资料治理、文档入库、运行审计、系统设置六个工作台页面。

## 本轮修订

1. **窄屏导航**：五项业务入口完整显示，不再依赖横向滑动。390px 下顶部由约 290px 缩至 177px；设置齿轮并入账号栏，不遮挡表单。桌面保留左侧固定可达的导航及底部设置入口。
2. **阅读层级**：统一标题、主要说明、表单边界和按钮高度。主操作采用暖橙底与深色字，保留蓝青渐变及隧道视觉元素。
3. **知识问答**：为问答场景、回答详细程度增加可见标签；手机两个选项并列、查询按钮独占一行；报告格式显示空间加宽，避免文字被箭头遮住。
4. **知识图谱**：工具栏、图例和摘要不再重叠。修复固定大尺寸 viewBox 导致手机节点文字缩至约 5px 的问题：相机适配当前画布和可见实体，复位重新适配；保持拖动、排斥、碰撞和连线牵引。两节点手机样例的实体与关系文字实际渲染尺寸均不低于 14px；大型图仍可使用层数控制与缩放查看。
5. **账号管理**：增强字段边界，刷新与帮助等入口扩大到至少 44px；手机长表单增加“返回账号目录（保留当前输入）”。跳转保留选中账号、未保存名称与内存中的密码输入，不保存密码到本地。
6. **键盘与状态**：增加“跳到主内容”入口，保留焦点与减少动态效果偏好；概览成功显示“工作台数据 · 已同步”，不再硬编码 DeepSeek 已连接。
7. **系统设置**：页标题统一为“系统设置”。登录页经实看布局正常，本轮不重复改版，共用样式变更仅作用于账号页。
