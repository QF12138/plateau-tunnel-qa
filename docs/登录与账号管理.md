# 登录与账号管理

- 登录页：`/login`，未登录访问工作台会跳转这里。
- “记住账号”仅在本机浏览器保存登录名，不保存密码，也不会延长 8 小时的登录期限。取消勾选即删除本机记忆；共用设备不建议开启。
- 支持显示/隐藏密码、大写锁定提醒、键盘操作和可展开帮助。错误密码会清空密码并聚焦；临时断网或超时保留输入，恢复网络后可重试。
- 提交过程中锁定表单、防止重复登录；连续失败触发限流后显示剩余秒数，倒计时结束可重试。限流为当前单进程演示服务的内存状态，重启后重置，不作为多实例部署方案。
- 未登录访问账号管理，登录成功后回到账号管理；只允许跳转本站工作台或账号管理，普通用户不会被引导到管理页。已有有效登录时无需重复输入。
- 登录过期、安全退出、修改账号后重新登录分别有明确提示。重新登录会替换当前浏览器旧会话，不影响其他设备；退出需校验 CSRF，并撤销服务器会话。
- 账号管理：管理员登录后，点击工作台左下方“账号管理”，或打开 `/accounts`。
- 支持新增账号、搜索账号、修改登录名/显示名称、设置管理员或普通用户角色、启用/停用、设置新密码。
- 账号目录可按角色、已启用/已停用/待设置密码组合筛选，显示匹配数量，支持一键清除筛选及单独刷新列表。
- 切换账号、取消、返回工作台或退出时，未保存内容会先确认；刷新/关闭浏览器时也有离开提示。不会将密码或账号草稿写入浏览器存储。
- 保存过程中锁定字段和账号切换。后端已保存而列表刷新失败时，界面明确提示已保存，保留返回账号 ID；点击刷新列表即可恢复，无需重复创建。
- 工作台独立显示当前登录账号与角色。另一个标签页退出后重新登录时，旧页面会暂停写入并提供“刷新身份”/“重新验证身份”入口，不自动重新提交旧操作。
- 启用普通账号：选中 `tunnel-reader`，输入两次新密码，选择“启用”，输入管理员当前密码，保存。
- 留空新密码保留已有密码；从未设置密码的账号不能直接启用。新增/修改密码至少 8 位。
- 保存会撤销被修改账号的已有登录。修改自己的账号后会跳回登录页，使用新信息登录。
- 不能停用或降级当前管理员，避免把自己锁在系统外。普通用户不能访问账号管理接口和页面。
- 不提供公开注册、短信或邮件找回密码；忘记密码应联系管理员。现有管理员初始密码保持不变。

首次迁移后，环境变量不再覆盖已保存的账号密码。启动脚本发现环境密码与页面管理的账号不一致时，不尝试覆盖；会检查登录页面和匿名认证保护，并明确显示“管理员登录未验证”。数据库恢复到新目录时清空会话，要求重新登录。

## 异常登录流程检查（2026-10-09）

- 复现并修复脚本加载失败时仍可提交原生 GET 表单的问题：原生表单明确使用 POST，登录按钮在脚本初始化完成前禁用；加载失败或关闭 JavaScript 时提供说明和无需脚本即可操作的重新加载链接，保留原登录目标。
- 非 JSON 的 401/429/网关错误不再丢失 HTTP 状态；限流支持秒数或日期格式的 Retry-After，异常值使用 60 秒回退。仅由用户手动重试，不自动重放登录或账号写操作。
- 登录结果必须确认成功且跳转目标在本站允许列表内，避免异常网关响应误显示登录成功。重新输入凭据会清除上一轮关联的错误标记。
- 新增 `tests/login_resilience_check.js`，31 项浏览器断言通过；既有登录流程、37 项账号管理检查及 35 项布局检查重新通过。所有错误模拟、账号新增/编辑验证都只在 8766 隔离预览中运行，未修改线上账号、密码或资料。

## 账号保存与刷新同步修复（2026-10-09）

- 保存响应先校验账号字段、目标 ID、提交内容、密码配置状态及重新登录标记，确认后才更新界面和清空密码。HTTP 成功但响应不完整时不再误报保存成功：保留当前输入、清除管理员确认密码，并提示先刷新核对；不会自动重试写入或重复创建账号。

## 身份校验与退出体验优化（2026-10-13）

- 账号页和工作台在使用身份响应前，统一校验账号 ID、登录名、角色、布尔管理权限及 CSRF 字段。兼容后台全部六类角色和本地/API 模式的 `csrf_token:null`；异常响应不再显示虚假的管理员身份或开放管理入口。后端权限校验保持不变。
